# CODEX AGENTS.md

AGENTS.md files are key components when using ChatGPT Codex agent.

This Repository Introduces some simple yet powerful AGENTS.md file examples.

## User Scope AGENTS.md

AGENTS.md files can be categorized into two types: user scope and project scope.

User scope AGENTS.md file lies within each PC's user account folder

```
User
    .codex
        /cache
        /memories
        AGENTS.md
        ...
```

When placed inside the correct location, the AGENTS.md file will be the first file to be automatically read by the session when initialized.

The User scope AGENTS.md file should entail the general working guideline for the agent.

The porvided example stems from Andrej Karpathy's CLAUDE.md file, tailored for CODEX usage.
